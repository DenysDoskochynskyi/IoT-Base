---

## Теоретичні відомості
- **AWS Lambda** — безсерверний обчислювальний сервіс, що дозволяє запускати код у відповідь на події.  
- **AWS IoT Core** — може генерувати події при надходженні даних від IoT-пристроїв.  
- **DynamoDB** — керована NoSQL-база даних від AWS, що добре підходить для швидкого зберігання телеметрії IoT.  

Зв’язка **IoT Core → Lambda → DynamoDB** дозволяє:  
1. Отримувати дані від пристроїв у реальному часі.  
2. Виконувати обробку даних усередині Lambda.  
3. Записувати результат у базу даних.  
4. (Опційно) Викликати інші сервіси чи Lambda-функції для подальшої обробки.  

---

## Завдання
1. **Створити таблицю DynamoDB**  
   - Таблиця з Primary Key `deviceId` (String).  
   - Додаткове поле `timestamp` для збереження часу події.  
   - Поле `value` для збереження показника (наприклад, температура).  

2. **Налаштувати IoT Core**  
   - Створити правило (IoT Rule), яке буде перенаправляти дані з топіка (наприклад, `iot/lab2/data`) у Lambda-функцію.  

3. **Розробити Lambda-функцію**  
   - Lambda має обробляти вхідні дані.  
   - Усередині функції перевіряти умови (наприклад:  
     - якщо температура > 30 → записати в DynamoDB;  
     - якщо температура ≤ 30 → проігнорувати, або зберігати з іншим тегом).  
   - Записати дані в таблицю DynamoDB у форматі:  
     ```json
     {
       "deviceId": "sensor-001",
       "timestamp": "2025-09-22T19:30:00Z",
       "value": 32
     }
     ```  

4. **Перевірити результат**  
   - Відправити тестові дані з IoT Core.  
   - Переконатися, що Lambda виконується.  
   - Перевірити таблицю DynamoDB на наявність записів.

## Приклад коду (AWS Lambda, Python 3.9)
```python
import json
import boto3
from datetime import datetime

dynamodb = boto3.resource('dynamodb')
table = dynamodb.Table('IoT_Lab2_Data')

def lambda_handler(event, context):
    # Вхідні дані від IoT Core
    print("Received event:", json.dumps(event))

    device_id = event.get('deviceId', 'unknown')
    value = float(event.get('value', 0))

    # Умова: зберігати тільки якщо value > 30
    if value > 30:
        response = table.put_item(
            Item={
                'deviceId': device_id,
                'timestamp': datetime.utcnow().isoformat(),
                'value': value
            }
        )
        print("Saved to DynamoDB:", response)
    else:
        print("Condition not met, skipping save.")

    return {"status": "done"}
```

---

## Очікуваний результат
- Дані з IoT Core надходять у Lambda.  
- Lambda виконує обробку та, за умовою, записує у DynamoDB.  
- У DynamoDB видно збережені записи.
