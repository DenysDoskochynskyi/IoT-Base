## Мета роботи
- Ознайомитися з основними принципами **шифрування даних**.  
- Розробити власний алгоритм шифрування та дешифрування.  
- Застосувати шифрування до MQTT-повідомлень, що передаються від IoT-пристрою.  

---

## Завдання
1. **Розробити власний алгоритм шифрування**  
   - Алгоритм може базуватися на простих принципах:  
     - шифр Цезаря;  
     - алгоритм перестановки;  
     - або будь-який інший придуманий студентом метод.  
   - Головне — продемонструвати **креативність** та **двосторонність** алгоритму (шифрування ↔ дешифрування).  

2. **Застосувати алгоритм у контексті MQTT**  
   - Перед відправленням MQTT-повідомлення **зашифрувати** його вміст.  
   - Шифрувати не JSON-об’єкт, а саме **payload** повідомлення.  
   - Зашифрованим має бути **як ключ, так і значення** повідомлення.  
   - Приклад:  
     ```
     Original message: temperature=25  
     Encrypted message: jgnnqtkpi=28  
     ```  

3. **Дешифрування повідомлення**  
   - Після отримання MQTT-повідомлення необхідно **дешифрувати** його.  
   - У лабораторній роботі можна реалізувати це у вигляді окремого **скрипта або функції**, яка розшифровує отримане повідомлення.  
   - У реальних умовах це б виконував бекенд або інший пристрій, який має відповідний ключ/метод.  

4. **Продемонструвати роботу алгоритму**  
   - Показати приклад:  
     - вихідного тексту,  
     - зашифрованого повідомлення,  
     - результату після дешифрування.

## Приклад (спрощений шифр Цезаря)
```python
# Приклад на Python
def encrypt(text, shift):
    result = ""
    for char in text:
        if char.isalpha():
            base = 'A' if char.isupper() else 'a'
            result += chr((ord(char) - ord(base) + shift) % 26 + ord(base))
        else:
            result += char
    return result

def decrypt(text, shift):
    return encrypt(text, -shift)

msg = "temperature=25"
encrypted = encrypt(msg, 3)
decrypted = decrypt(encrypted, 3)

print("Original:", msg)
print("Encrypted:", encrypted)
print("Decrypted:", decrypted)
```
